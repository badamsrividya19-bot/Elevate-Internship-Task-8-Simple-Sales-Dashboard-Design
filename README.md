Elevate Internship — Task 8
Simple Sales Dashboard Design (Advanced Submission)

This repository contains the submission for Elevate Internship — Task 8, which focuses on designing a simple yet informative sales dashboard using a sample Superstore dataset.
The task includes data preparation, visualization, dashboard building, and insight extraction.

1. Project Overview

The objective of this task is to create a Sales Dashboard that displays key performance trends using sample retail (Superstore-style) data.

This project includes:

Creating a sample Superstore sales dataset

Cleaning and preprocessing data

Generating static visuals:

Line chart — Sales Over Months

Bar chart — Sales by Region

Donut chart — Sales by Category

Building an interactive dashboard using Plotly (HTML file)

Creating a professional PDF report containing visuals & insights

Packaging all deliverables into a GitHub-friendly format

The dashboard and charts help understand sales distribution, high-performing categories, regions, and overall monthly trends.

2. Dataset Structure

The dataset (Superstore_Sales_sample.csv) contains the following fields:

Column Name	Description
Order Date	Date of the transaction
Region	Customer region (West, East, Central, South)
Category	Product category (Office Supplies, Furniture, Technology)
Sales	Sales amount for the transaction
Profit	Profit earned

The dataset was artificially generated for demonstration purposes and represents one full year of retail activity.
